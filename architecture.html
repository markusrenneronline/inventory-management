Factory Inventory Management System

Architecture overview: Vue 3 SPA, FastAPI REST backend, in-memory JSON data (no database).

Data flow

  1. Filter change. The user changes Time Period, Warehouse, Category or Order Status. State is held in shared refs in useFilters.js (singleton).
  2. Request. A view calls api.js, which adds only non-all filters as query params and sends the request to http://localhost:8001/api.
  3. Filtering. The FastAPI route runs apply_filters and filter_by_month (months and quarters such as Q1-2025) on the lists loaded in memory.
  4. Validation. Results pass through the Pydantic response models and are returned as JSON.
  5. Rendering. The view stores the raw data in refs (allOrders, inventoryItems) and derives all displayed values in computed properties.

Inventory has no time dimension, so it ignores the month filter. Data is read-only and resets on restart.
